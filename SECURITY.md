# Security

Security fixes target the latest published alpha version.

Use [GitHub private vulnerability reporting](https://github.com/getridian/ridian-mailbox-python/security/advisories/new)
to report a vulnerability. Include affected versions, a minimal reproduction with
synthetic data, and the expected impact. Do not post credentials, personal email,
or exploit details in a public issue. If private reporting is unavailable, use
the contact listed at [getridian.com](https://getridian.com/).

State files contain access credentials and claim proofs. Keep them outside the
repository, on durable private storage, and use one writer per file. Never attach
state files to bug reports. Treat all email and attachment content as untrusted.
